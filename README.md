# MultiLib

A desktop library for your games and anime on Windows.

This repository holds the releases only. To get MultiLib, open [the latest release](../../releases/latest) and download:

- `MultiLib-Setup-<version>.exe`: the installer
- `MultiLib-Portable-<version>.exe`: runs without installing and keeps its data next to the file
- `MultiLib-extension-<version>.zip`: the optional browser extension

Each release's page lists what changed.
